# Образцы моделей

Где лежит: `Warfare1347\ArtSource\reference\kenney\` (в git не попадает, наборы можно скачать заново).
Посмотреть: открыть `ArtSource\reference\index.html` в Chrome — у каждой модели картинка и имя. Страницу пересобирает `py Tools/reference_index.py`.

Как работаем: модели Kenney — образцы, а не детали игры. Смотрим силуэт, пропорции и из каких крупных частей собрана вещь, а свою модель делаем скриптом в Blender (`Tools/blender/`) с нашими материалами и узорами, чтобы весь мир был в одном стиле. При необходимости модель Kenney можно открыть в Blender (папки `Models/FBX format`, `GLB format`, `OBJ format`) и снять с неё размеры.

Лицензия у всех наборов CC0: можно использовать как угодно, указывать автора не обязательно. Файл лицензии лежит в папке каждого набора. Скачано 2026-10-17 с разрешения Дениса.

## Blender Studio

`ArtSource/reference/blender-studio/human-base-meshes/` — набор «Human Base Meshes» v1.4.1 от Blender Studio (blender.org, CC0, 49 МБ): тела, головы, кисти, стопы, глаза, реалистичные и стилизованные. Основа для тела героя — `GEO-body_male_stylized` (12,5 тыс. вершин, рост 1,8 м). Скачано 2026-10-17 с разрешения Дениса.
