### Меняем для ПК и 3D
| Что | В мобильной версии | В ПК-версии |
|---|---|---|
| Поле боя | полоса 2400×142 px сбоку, глубина сжата перспективой | настоящая плоскость в метрах (например 300×200 м), направление бойца — угол, а не «влево/вправо» |
| Численность | до 36 бойцов на сторону, остальные волнами | до 150 на сторону, остальные волнами |
| Управление боем | кнопки групп и приказов | как в Mount & Blade: выбрать отряд (1–4, 0 — все) → выбрать команду в меню F1/F2/F3; камера стратегии |
| Графика | 2D, фигуры рисуются кодом из снаряжения | Свой облик, не копия мобильной: 3D-«чибики» из Blender (см. «Облик персонажей») + модули шлема, доспеха, щита, оружия, коня |
| Анимации | процедурные покачивания | Mixamo на скелете Humanoid |
| Карта мира | 2D-рисунок по контурам Natural Earth | 3D-карта с рельефом по тем же контурам (`land.json`) |
| Интерфейс | HTML/CSS | Unity UI Toolkit (по устройству ближе всего к HTML/CSS) |
| Сохранения | localStorage, 3 ячейки | JSON-файлы в папке игрока, больше ячеек |
| Музыка и звук | синтез на WebAudio | бесплатные записи со свободной лицензией (CC0 и подобные) |
| Случайность | `Math.random` в 69 местах | один ГСЧ с зерном: бой воспроизводим, его можно проверить тестом |

## 2. Архитектура

```
Assets/
  Game/
    Core/            Warfare.Core.asmdef — чистый C#, без UnityEngine
      Data/          описания (TroopDef, ItemDef, ...) и загрузка JSON
      Battle/        симуляция боя
      World/         карта, отряды, войны, экономика, поручения, ...
      Save/          сохранение и загрузка
      Util/          ГСЧ, математика на плоскости
    Core.Tests/      NUnit (Edit Mode)
    Client/          Warfare.Client.asmdef — сцены, камера, ввод, отображение, интерфейс
  StreamingAssets/Data/   troops.json, items.json, factions.json, lords.json, settlements.json, i18n/*.json
Tools/
  CoreTests/         .NET-проект: собирает Core и Core.Tests для `dotnet test` без Unity
  export-data/       скрипт переноса данных из мобильной версии в JSON
```

- **Ядро ничего не знает о Unity.** Клиент каждый кадр читает его состояние (позиции, здоровье, события боя)
  и показывает, а команды игрока передаёт вызовами (`SetOrder`, `PlaceGroup`, ...).
- **Фиксированный шаг:** бой считается шагами по 1/30 с, клиент сглаживает движение между шагами.
  Автобой — та же симуляция без картинки.
- **JSON** читаем через Newtonsoft.Json (пакет Unity `com.unity.nuget.newtonsoft-json`, бесплатный, официальный).
- **Расширяемость данных:** у воина и предмета — открытые списки особенностей (`traits`) и тегов; виды оружия,
  брони и щитов — строковые ключи из JSON, а не жёсткий перечень в коде. Ветки войск — граф `upgradesTo` любой глубины.

### Этап 2. Полный бой
**Герой под управлением игрока.** Бой делится на две фазы:
- **Планирование (расстановка):** камера стратегии, игрок расставляет отряды по полю.
- **Сражение:** камера привязана к герою — вид сверху-сбоку под постоянным углом, как в Diablo (2.5D);
  герой ходит на WASD, поворачивается к курсору, бьёт и блокирует в сторону курсора, приказы отрядам — по-прежнему клавишами 1–4/0 и F1/F2/F3, как в Mount & Blade.
  Появляется приказ «За мной» (F1 → F2). В ядре мобильной версии такое управление уже было (`HeroControl`).

Строи, особенности войск, таран конницы, полёт снарядов, знаменосец, фланг и тыл, поддержка, местность (холмы, рощи,
брод, телеги), погода, ночь, засада, погоня, подкрепления, автобой, итоги боя, осада со стеной, турнирная арена.
Баланс сверяем с мобильной версией: одни и те же армии должны побеждать примерно с той же частотой.
