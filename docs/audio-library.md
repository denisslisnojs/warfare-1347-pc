# Библиотека звуков

Где лежит: `Warfare1347\ArtSource\audio\library\` (в git не попадает, это сторонние наборы, их всегда можно скачать заново).
Послушать: открыть `ArtSource\audio\library\index.html` в Chrome и нажимать ▶. Страницу пересобирает `py Tools/audio/library_index.py`.

Как добавить звук в игру: назвать мне набор и имя звука со страницы (например, «rpg-audio, handleCoins»), я скопирую его в игру и подключу к нужному действию.

## Наборы

Все наборы Kenney (kenney.nl), лицензия CC0: можно использовать в любой игре, в том числе платной, указывать автора не обязательно. Файл лицензии лежит в каждой папке набора.
